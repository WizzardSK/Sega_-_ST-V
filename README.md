# Sega - ST-V

Thumbnails for Sega ST-V games, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails) (`Named_Snaps`, `Named_Titles`, `Named_Boxarts`), named after the games' MAME short names, as the MAME `stv` software list has them.

Snaps (in-game), titles and flyers (as boxarts) from the [Arcade Database](https://adb.arcadeitalia.net/); 29 of the 53 games have a flyer there.
